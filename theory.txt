2. DNA, RNA, Protein & Seq Class in Biopython
DNA, RNA, Protein
DNA (Deoxyribonucleic Acid):
Stores genetic information
Bases: A, T, C, G
RNA (Ribonucleic Acid):
Involved in protein synthesis
Bases: A, U, C, G (U replaces T)
Protein:
Chain of amino acids
Performs cellular functions (enzymes, structure, etc.)
Seq Class (Biopython) – Key Operations
Slicing: Extract subsequences
Concatenation: Join sequences using +
Transcription: DNA → RNA
Translation: RNA → Protein

Keywords: Genetic code, codons, sequence manipulation

3. GenBank Format & SeqRecord
GenBank Format
Stores:
Sequence data
Gene names
Functions
Features (exons, CDS)
SeqRecord Object
Components:
Seq (sequence)
ID, Name, Description
Annotations (metadata)
Features (regions)
Used for:
Organizing sequence data
Exporting to GenBank

Keywords: Annotation, metadata, biological features

4. FASTA vs GenBank
FASTA Format
Simple format
Contains:
Header (>)
Sequence only
GenBank Format
Detailed format
Contains:
Sequence + annotations + features
Conversion Process
Read FASTA
Create SeqRecord
Add annotations
Write to GenBank

Keywords: File formats, sequence storage, conversion

5. SeqRecord Components & Usage
Main Components
Seq: Biological sequence
ID: Unique identifier
Name/Description: Basic info
Annotations: Metadata
Features: Regions (gene, CDS, exon)
Operations
Add/modify annotations
Add features with location
Update metadata

Keywords: Data structure, feature annotation
